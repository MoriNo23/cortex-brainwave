# Cortex — protocolo de escucha manual

Esta prueba necesita una persona con auriculares o parlantes reales. No mide HRTF ni demuestra un efecto médico; registra una observación subjetiva de la salida audible.

## Seguridad

- Usar un volumen inicial muy bajo.
- No probar si hay dolor, tinnitus activo, hipersensibilidad o molestia.
- Detener inmediatamente ante zumbido, distorsión, mareo, dolor o fatiga.
- No usar la app como tratamiento médico.
- Hacer sesiones cortas y descansar entre configuraciones.

## Resultado

- [ ] PASS subjetivo: comportamiento audible coherente y cómodo en el dispositivo probado.
- [ ] FAIL subjetivo: artefactos, canal ausente, clicks, clipping o comportamiento inesperado.
- [ ] MANUAL-PENDING: no se realizó aún la escucha.

**Nota:** una respuesta positiva no valida HRTF real ni localización frente/atrás. Solo documenta la experiencia de escucha de un dispositivo concreto.
