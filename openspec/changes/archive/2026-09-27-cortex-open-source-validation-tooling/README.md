# cortex-open-source-validation-tooling

Propuesta para investigar herramientas open source que ayuden a cerrar los gaps restantes de Cortex.

Esta propuesta no adopta automáticamente webMUSHRA, libmysofa, Resonance Audio, Omnitone, BackstopJS, Storybook, Playwright, Difftastic o ast-grep. Primero exige comprobar licencia, mantenimiento, compatibilidad y ajuste funcional.
